从水墨黑白，
到纸上海洋。

SimApp 原有界面是一套克制的水墨黑白主题，信息密度高，但层级偏平、状态不够醒目。这次改版保留它的秩序感，换上更温暖、更有触感的视觉语言：奶油纸底、海军蓝描边、硬投影与一点珊瑚色的行动号召。

改版做了什么

视觉与交互层面的重构，不改业务逻辑

色彩奶油纸底替代纯白，墨蓝替代纯黑，电光蓝只用于可交互元素。
层级页头、统计、内容、侧栏四段式；每屏只保留一个主行动。
状态审批、权限、同步等关键状态都有色彩与文案双重表达。
触感2px 描边与无模糊硬投影，让卡片像贴纸一样落在纸面上。
可达性键盘可遍历、焦点环可见、表格有表头、弹层可 Esc 关闭。
