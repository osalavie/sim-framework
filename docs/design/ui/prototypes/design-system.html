描边

硬投影

无模糊，偏移 2–6px，颜色与描边一致。

圆角

卡片 16px、按钮 999px、输入 12px。

列表页骨架

1. 页头：后台仅保留指标与主行动（页面标题由顶栏承担）；记录详情保留标题层级
2. 统计条：3–4 个关键数字，不重复表格信息
3. 工具栏：搜索、筛选、批量操作
4. 数据表 / 卡片列表
5. 分页或加载更多

详情页骨架

1. 返回路径与对象标题
2. 状态与关键字段（KV 网格）
3. 主内容：表单 / 时间线 / 日志
4. 右侧：属性、关联对象、危险操作
5. 底部固定操作栏（有未保存改动时出现）

状态与反馈

暂无数据

调整筛选条件，或新建第一条记录。

加载中

骨架屏保持与真实内容相同的行高。

出错了

给出原因与下一步，而不是只显示错误码。

可达性：所有交互元素保留 2px 可见焦点环；正文对比度不低于 4.5:1；动效在 prefers-reduced-motion 下关闭位移。
原则 01

先让人看懂

每个页面只回答一个问题。标题说人话，术语放进说明里。

原则 02

状态永远可见

加载、空、错误、成功都有明确反馈，禁止静默失败。

原则 03

危险操作慢一点

删除、驳回、轮换密钥需要二次确认，并说明后果。
