Theme proposal · 2026.10

商务主题 · 中国传统色

不是给现有界面换一层颜色，而是用「传统色 + 商务皮肤」重建一套更克制的视觉语言：发丝边、柔光阴影、收敛圆角、实心主按钮。纸上海洋保留为一套独立风格，商务主题只作用于选择它的用户。

候选色系3 套
每套模式月白 / 玄夜
结构基准1px 边 · 8/14px 圆角
对比度正文 ≥ 7:1 · 次级 ≥ 4.5:1
色从传统，序从商务

颜色取自玄青、黛蓝、竹青、朱砂、缃色等传统色；层级关系遵循后台信息密度，而不是装饰性配色。

一个主色，一个强调色

主色只负责交互与主行动，强调色只负责选中、指标与印章式点缀。避免每个按钮都在抢注意力。

明暗同源，不另做一套

每套主题的明暗共享同一组语义角色，只调整明度与饱和；换模式时版式、圆角、间距完全不变。

商务皮肤独立成层

纸上海洋的 2px 墨线与硬投影不被破坏；商务皮肤通过独立 token 层生效，可单独验收、单独回退。

结构边

新增 --po-edge，替代 2px --po-ink 描边。默认 1px，悬停 1px --po-edge-strong，焦点 2px 主色 + 3px 光环。

投影

卡片 0 1px 2px / 0 10px 28px；弹层 0 4px 12px / 0 18px 48px；弹窗 0 24px 64px。全部低透明度，不再使用墨色偏移。

圆角

控件 8px、按钮 8px、卡片 14px、弹层 12px、弹窗 18px、标签 999px。相比现有的 16/24px 更收敛。

主按钮

实心主色 + 同色 1px 边 + 米白文字；悬停加深 8%，按下加深 14%；焦点环 3px 主色 14% 透明度。次按钮为白底 + 发丝边。

字体层级

展示字重 900 → 600，标题 600，正文 400；正文 14px / 1.7；数字统一 tabular-nums，金额与编号右对齐。

表格与标签

表头用次级底；行分隔 1px；悬停主色 5%；标签改为同色 1px 描边 + 8% 底；状态点保留，但去掉粗描边。

需要你拍板

  1. 2 套还是 3 套？范围选的是「保留纸上海洋 + 新增 2 套」，但色系选了三套。建议三套都保留：实现成本主要在令牌/皮肤层，新增一套主要是配色验收与截图回归。
  2. 商务皮肤是否按此收敛？重点是 1px 发丝边、柔光阴影、实心主按钮。如果希望保留更强的「纸感」，可以把边改回 1.5px、阴影保留一层极轻的偏移。
  3. 朱缃的危险色暂用绛红 #8C3A42，与主色朱砂区分；如果希望危险操作也保持朱砂同色，我会改为同色 + 图标/文案区分。
